# poster-design

Claude Code plugin that designs social media posters with a real human touch —
bold flat brand colors, asymmetric photo-dominant layouts, shaped CTAs and
real-business contact furniture — instead of AI-looking gradients and centered
heroes.

By srinu desetti.

## Install

```
claude plugin install /path/to/poster-design
```

## Use

Ask Claude to design a poster ("make an Instagram post for my laundry service,
brand color blue"). The `poster-design` skill triggers automatically.

Add your own reference screenshots to
`skills/poster-design/references/refs/` — Claude studies them before designing.
